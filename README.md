## 🎯 Development Philosophy

### "사용자 중심 사고"
4년간 매장 근무 경험을 통해 사용자 요구사항을 파악하고 분석하는 능력을 기름. 이를 바탕으로 개발할 때도 사용자 경험을 최우선으로 고려.

### "점진적 성장"
완벽보다는 실행을 우선하여 일단 동작하는 코드를 구현한 후 점진적으로 개선하는 방식으로 접근. 이를 통해 프로젝트 완성도와 개발 속도 향상.

### "체계적 학습"
비전공자로서 부족한 CS 기초 지식을 보완하기 위해 학점은행제 컴퓨터공학 학사 과정을 병행하고 있습니다.
